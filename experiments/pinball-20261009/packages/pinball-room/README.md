# Pinball shared room protocol

The authority admits owner input and sends public Frame@2 state. Full packets use binary version2, include capture occupancy, visible transport phases and activation serials, and bind the static dictionary, accepted roster, world digest, kernel and authority revision. Delta packets preserve the exact full bytes and require their current checksum baseline; rejected packets do not replace that baseline.

Capture decoding verifies the parked body's real mouth, height, inactive state, occupancy, exact timer schedule, destination, wait deadline and compound route qualification. Transport is an explicit recorded mechanism; ordinary ramp travel remains a visible active ball. Public packets contain no arbitrary body-placement command or private replay snapshot.

The event journal retains launch, skill, route, capture and other admitted actions until publication. Contact cues coalesce by owner; mechanism cues coalesce by static mechanism ID because the frame already preserves activation serials. Independent rotating cursors share spare packet capacity. Reliable overflow or a missed one-second publication deadline fails explicitly. Body counts and shared-arena geometry capacity require their own admission; a protocol round trip alone does not prove a playable100-player match.
