# Spatial pinball arena view

An optional KEEL renderer for `@keel-engine/pinball-arena` worlds and frames. It has no dependency on the discarded cabinet renderer. Meshes come from actual world polygons, physical mechanisms and `packs/pinball-world-art` styled designs, then pass through KEEL's live mesh renderer, material lookup, palette screens, shadows and depth.

```ts
const view = createPinballArenaView(canvas, {
  ownerId: 0, width: innerWidth, height: innerHeight,
  style: "pixel", density: "medium", reducedMotion: false,
});
view.setWorld(world);
view.render(frame, { timeMs, deltaMs, camera: { mode: "follow", ownerId: 0 } });
// Connected arenas have independent physics grids and presentation-only map offsets.
view.render(frame, { timeMs, camera: { mode: "overview", scope: "world" } });
view.dispose();
```

Physical x/y/elevation become renderer x/Y/z through `world.unitScale`. Art yaw uses radians; mechanisms use the canonical frame endpoints. Geometry style and region materials are independent of the presentation choices `pixel`, `dither`, `arcade`, `realistic`, and `cartoon`.

The declared shooter mouth mounts a bounded spring/plunger. Wireform routes retain their actual source support deck and open framework details, keeping crossbars narrower than the body. The body aperture resolves actual layered occlusion locally. This presentation does not declare capture, alter support or excuse a failed route sightline. Empty scenery chunks are valid: the follow view still admits the complete static physical mesh. Declared ports place shallow directional inlays, distinguish shot mouths from return mouths, and show completion only through their explicit qualification identity. Drains use their canonical hazard aperture and danger rim.
